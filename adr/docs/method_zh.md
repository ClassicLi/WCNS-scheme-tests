# ADR 方法说明

## 1. 近似色散关系

ADR（Approximate Dispersion Relation）由 Pirozzoli (2006) 提出，用于估计非线性
格式的修正波数。对周期区间上的单模态初值

```
u_0(x_j) = cos(n · 2π j / N),   j = 0..N-1,
```

推进一个很小的时间步 `dt`，得到 `u_t`。对初值与终值分别做离散 Fourier 变换：

```
û_n = (1/N) Σ_{j=0}^{N-1} u_j exp(-i n 2π j / N).
```

修正波数定义为

```
Phi_n = 2π i ln(û_t / û_0) / (dt · N).
```

横轴为 `varphi_n = 2π n / N`。`Re(Phi)` 描述色散，`Im(Phi)` 描述耗散；
线性对流方程的精确关系为 `Phi = varphi`（实轴）。

## 2. 网格与模态

- `mesh_num` 必须为奇数；默认 `827`。偶数网格可能出现振荡。
- 模态编号 `n = 0..mesh_num/2`（整除），输出 `mesh_num/2 + 1` 个点。
- 奇数网格没有 Nyquist 模态，最后一个点的 `varphi` 略小于 `π`。

## 3. 时间推进

采用三步三阶 Runge–Kutta：

```
u^(1) = u^n + dt R(u^n)
u^(2) = 3/4 u^n + 1/4 u^(1) + 1/4 dt R(u^(1))
u^(n+1) = 1/3 u^n + 2/3 u^(2) + 2/3 dt R(u^(2))
```

每一步之前刷新周期边界。`dt` 足够小，使时间离散误差不污染 `Phi` 的提取。

## 4. 精度与 dt

`û_t/û_0` 与 1 的差约为 `dt` 量级；在 `ln` 中提取该小量会损失有效数字。因此：

- 四精度（`PRECISION=qp`，默认）：`dt = 1e-20`，保留约 13 位有效数字。
- 双精度（`PRECISION=dp`）：`dt = 1e-10`，保留约 6 位有效数字；高波数处噪声更明显。
- `input.nml` 中 `dt = 0` 表示按构建精度自动选择。

## 5. 两套空间离散

### 5.1 WENO 重构（`adr_weno`）

在 `j+1/2` 处重构数值通量 `f_{j+1/2}`，再用固定二阶通量差分：

```
R_j = -(f_{j+1/2} - f_{j-1/2}) / h.
```

WENO 侧不提供差分套子选择。

### 5.2 WCNS 插值（`adr_wcns`）

先用标准件在半节点插值得到 `u_{j+1/2}`，再选择差分套子：

```
WCNSE2: R_j = -(f_{j+1/2} - f_{j-1/2}) / h
WCNSE4: R_j = -[ 9/8 (f_{j+1/2}-f_{j-1/2}) - 1/24 (f_{j+3/2}-f_{j-3/2}) ] / h
WCNSE6: R_j = -[ 75/64 (f_{j+1/2}-f_{j-1/2}) - 25/384 (f_{j+3/2}-f_{j-3/2})
                + 3/640 (f_{j+5/2}-f_{j-5/2}) ] / h
HCS4:   R_j = -[ 4/3 (f_{j+1/2}-f_{j-1/2}) - 1/6 (u_{j+1}-u_{j-1}) ] / h
HCS6:   R_j = -[ 64/45 (f_{j+1/2}-f_{j-1/2}) - 2/9 (u_{j+1}-u_{j-1})
                + 1/180 (u_{j+2}-u_{j-2}) ] / h
```

`HCS4` 与 `HCS6` 同时使用半节点通量与整节点值；`HCS6` 是“一对半点 + 两对整点”。

## 6. 差分套子的选择

**同一插值格式、不同差分套子，ADR 曲线不同。** 原因是 `Phi` 反映的是“插值 + 差分”
整体算子的频谱，而不是单独插值的频谱。因此做格式对比时，应选择实际计算中该格式
对应的套子；跨套子比较不能说明格式本身的优劣。

## 7. 边界与 halo

- `adr_weno`：halo = 9，覆盖最宽的 `WENO5_DLR` 模板与 TENO 模板。
- `adr_wcns`：halo = 7，覆盖 `interpolate_dispatch` 的 `u(-3:4)` 与 `HCS4/HCS6` 的整节点读取。

## 8. 限制

- 未验证格式（`THINC`、`TENO_333_RBF`、`WENO5_DLR`）保留为实验子程序，结果不保证。
- WENO 五阶线性重构是 WENO 最优重构（单元平均意义），不是点值五点插值；
  不应对其断言多项式点值精确性。
- 旧版程序的 `.dat` 输出不作为本程序的复现或回归目标。
