# 公式与实现核对

## 1. 差分套子

`flux_half(1:6)` 映射 `E_{j-5/2}..E_{j+5/2}`；`u_node(1:5)` 映射
`u_{j-2}..u_{j+2}`。所有算子返回 `K_j = -(...)/h`。

```
WCNSE2: -(E_{j+1/2} - E_{j-1/2}) / h
WCNSE4: -[ 9/8 (E_{j+1/2}-E_{j-1/2}) - 1/24 (E_{j+3/2}-E_{j-3/2}) ] / h
WCNSE6: -[ 75/64 (E_{j+1/2}-E_{j-1/2}) - 25/384 (E_{j+3/2}-E_{j-3/2})
          + 3/640 (E_{j+5/2}-E_{j-5/2}) ] / h
HCS4:   -[ 4/3 (E_{j+1/2}-E_{j-1/2}) - 1/6 (u_{j+1}-u_{j-1}) ] / h
HCS6:   -[ 64/45 (E_{j+1/2}-E_{j-1/2}) - 2/9 (u_{j+1}-u_{j-1})
          + 1/180 (u_{j+2}-u_{j-2}) ] / h
```

`HCS4` 与 `HCS6` 的整节点项在二维 Euler 中传入**物理通量** `Eint/Gint`，
不是守恒变量 `Ubar`；标量一维测试中二者相同。

`HCS6` 的系数由 Taylor 展开匹配到六阶得到：
`a + 2b + 4c = 1`、`a/24 + b/3 + 8c/3 = 0`、`a/1920 + b/60 + 8c/15 = 0`，
解得 `a = 64/45`、`b = -2/9`、`c = 1/180`。

套子实现与 `adr/src/wcns/difference_operators.f90`、
`complex_wave/src/wcns/difference_operators.f90` 同源。

## 2. 与旧程序的差异

| 项目 | 旧程序 | 本实现 |
|------|--------|--------|
| 一维 halo | `U(-5:N+5)` 配 `j=-3..N+2`，会读到 `u(-6)`、`u(N+6)` | `halo = 7`，修正越界 |
| 二维 halo | `MT = 5`，只循环到 `j=-1..N` | `mt = 7`，通量扩到 `j=-3..N+2`，覆盖插值与套子最远读取 |
| 二维套子 | `RungKutta` 硬编码 HCS6 系数 | `difference_apply` 按 `HCS4/HCS6` 选择 |
| 二维精确解 | 后处理器单独一份，含绝对路径 | `e2d_cases` 统一提供初值与精确解 |
| 一维初值 | 注释开关 + 单独 `Exact.dat` | `initial_1d` 选择，`c1d_profile` 唯一公式 |
| 结果路径 | 相对/绝对路径混用 | 全部相对 `output_dir` |

旧 `_jcp` 数据还混有等熵涡与 `2π` 正弦算例；本子项目只实现等熵涡与
`sine` 两套算例，不把旧数据当逐值回归目标。

## 3. 移植验证

二维管线用 `LINEAR5_M2P2 + HCS6` 跑 `vortex`（`nbase=40`，三层），
与旧 `2d_accuracy_test_final_output/linear5.dat` 对照：

- `n=40`：L1 `3.67798274077e-5`，L2 `1.60112910422e-4`，L∞ `2.18996194315e-3`；
- `n=80`：L1 `2.0115233688e-6`，L2 `9.7458371602e-6`，L∞ `1.6975612608e-4`；
- `n=160`：L1 `7.120393244e-8`，L2 `3.486510455e-7`，L∞ `5.745653305e-6`。

旧表对应值为 `3.67798274077e-5`、`2.01152336879e-6`、`7.12039324098e-8`
（L1），相对差约 `1e-15`。二阶/无穷范数与阶数同样一致，确认二维通量、
特征分解、Steger–Warming 分裂与套子调用的移植正确。

## 4. 实测阶数与解释

- `Z5 + HCS6` 在光滑 `sine` 上约 5 阶；线性 `LINEAR5_M2P2 + HCS6` 在
  `vortex` 上约 5 阶。
- `Z3`/`QR + HCS4` 在临界点附近出现 L1 约 2、L∞ 约 1–2 的降阶。
  `interpolation/` 子项目的 `Z3_udf3.csv`、`QR_udf3.csv` 同样显示
  L∞ 约 2、L1 约 2.6–2.9，说明这是三阶非线性权在临界点的已知行为，
  不是本实现的索引或边界错误。
- 二维强等熵涡上 `Z5` 的 L1 阶数从约 3 升到 `n=320` 的约 4.3，旧
  `js5.dat` 为 3–4 阶；线性 `LINEAR5_M2P2` 保持 5 阶。差异来自非线性
  光滑因子，不是通量管线。

## 5. 边界说明

一维插值在 `j = -3..N+2` 需要 `u(-6)` 与 `u(N+6)`，二维通量循环同样在
`j = -3..N+2`、`k = -3..M+2` 上读取 `j-3`、`k-3`。因此 halo 必须至少为 6；
本实现统一取 7（一维 `halo`、二维 `mt`），并用 `-fcheck=all` /
`-check bounds` 验证无越界。
