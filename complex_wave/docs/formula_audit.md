# 公式与参考程序对照 / Formula Audit

参考程序为作者开发本章算例时使用的版本（`main.f90`、`solver.f90`、`tools.f90`、
`interpolation_chap3.f90`、`interpolation_5th_order.f90`），未随本仓库发布。本文件
只记录该程序与本实现的公式和输出差异；文中公式均可独立核对。

## 1. 参考程序做了什么

- 方程：`u_t + u_x = 0`，域 `[-1,1]`，周期边界，波速 1。
- 初值：高斯峰、方波、三角波、半圆；高斯与半圆用 `(f(x-δ)+4f(x)+f(x+δ))/6`，
  `δ = 0.005`。
- 空间：`Z5_interpolation` 给出半节点通量，`Difference_E6` 给出节点导数；
  `Difference_E4`、`Difference_E2` 在源码中被注释掉。
- 时间：四步四阶 RK，`CFL = 0.3`，`Tend = 8`（即 4 个周期），最后一步截断到
  `Tend`。
- 输出：初值 `Exact.dat` 与终值 `z5_200_t8.dat`；没有解析终值，也没有误差统计。

## 2. 本实现的差异

| 项目 | 参考程序 | 本实现 | 原因 |
|------|----------|--------|------|
| halo | `U(-5:N+5)` | `u(-7:N+7)` | `Interp(u_{j-3..j+4})` 在 `j=-3` 需要 `u(-6)`、在 `j=N+2` 需要 `u(N+6)`；参考数组的 `-5:N+5` 会越界读取（out-of-bounds）。`halo = 7` 修正该缺陷。 |
| 差分套子 | 源码里写死 `Difference_E6` | `WCNSE2`、`WCNSE4`、`WCNSE6`、`HCS4`、`HCS6` 可选 | 用户要求套子可选。 |
| 新增 `HCS6` | 无 | 一对半点 + 两对整点 | 见第 3 节。 |
| 终止时间 | `Tend = 8` 写死 | `periods`（默认 4），`Tend = periods × 2` | 用户要求推进周期数可自定义。 |
| 输出 | 初值与终值两个文件 | 每周期快照（`t = 0, T, ..., periods*T`） | 用户要求按周期输出并与初值比较。 |
| 结果统计 | 无 | 无误差范数；只记录极值与 `nan_count` | 用户明确不输出误差统计，也不做格式矩阵。 |
| 默认精度 | `precision = dp` | `dp` 默认，`qp` 可选 | 用户要求默认双精度。 |
| 插值参数 | `Z5` 用 `PARA_Q = 4.0`；`JS3` 的 `p` 在参考中为 1 | 复用仓库标准件：`Z5` `q = 2`、`JS3` `p = 2` | 与 `interpolation/`、`adr/` 的标准件保持一致；用户 2026-11-21 为 ADR 定过该参数。 |
| 网格 | `N = 200` | `mesh_num = 200`（可配） | 与参考结果可比；仍允许自定义网格。 |

## 3. `HCS6` 的来源与核对

参考程序 `lax` 算例中的 `solver.f90`（`Difference_hcs6`）为

```fortran
a = 64.0D0/45.0D0
b = -2.0D0/9.0D0
c = 1.0D0/180.0D0
K = a*(Ehalf(4) - Ehalf(3)) + b*(E_int(1) - E_int(-1)) + c*(E_int(2) - E_int(-2))
K = -K/h
```

这正是“一对半点 + 两对整点”的混合紧致套子。用 Taylor 展开独立核对：

```
a + 2b + 4c = 1
a/24 + b/3 + 8c/3 = 0
a/1920 + b/60 + 8c/15 = 0
```

代入 `a = 64/45`、`b = -2/9`、`c = 1/180` 后三式均成立，因此 `HCS6` 为六阶。
本实现的 `hcs6` 子程序逐项对应上述公式，数组映射为 `Ehalf(1:6)` →
`flux_half(1:6)`、`E_int(-2:2)` → `u_node(1:5)`。

## 5. 结果配对

按用户 2026-11-22 的决定：

- 五阶插值 `JS5`、`Z5` 配 `HCS6`；
- 三阶插值 `JS3`、`Z3`、`QR` 配 `HCS4`；
- 网格 `200`，推进 4 个周期，三阶与五阶分开出图；
- 不做格式 × 套子矩阵，不做误差统计。
