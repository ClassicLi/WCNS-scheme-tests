# euler1d 方法说明

## 1. 控制方程

```
∂U/∂t + ∂E/∂x = 0
U = (ρ, ρu, ρE)^T
E = (ρu, ρu² + p, (ρE + p)u)^T
p = (γ - 1)(ρE - 0.5 ρu²),  γ = 1.4
```

## 2. 网格与初值

单元中心网格 `x_j = j h`，`j = 0..N`，`h = L/N`。
Sod/Lax 的 `L = 1`，Shu-Osher 的 `L = 10`。初值在 `j = 0..N` 上给定，
halo 由零阶外推填充。Sod/Lax 的间断在 `j = N/2` 与 `N/2+1` 之间；
Shu-Osher 的左段为 `j < N/10`，右段从 `j = N/10` 开始。

## 3. 特征变量插值

设中心点 `U_0 = (ρ, ρu, ρE)`，`u = ρu/ρ`，`c² = γp/ρ`，`α = u²/2`，
`β = γ - 1`。左右特征矩阵为

```
ml = [ αβ - c²,      -βu,      β ]
     [ αβ - c u,   c - βu,     β ]
     [ αβ + c u,  -c - βu,     β ]

mr = 0.5/c² *
     [ -2,          1,                 1                ]
     [ -2u,         u + c,             u - c            ]
     [ -2α,         α + cu + c²/β,     α - cu + c²/β    ]
```

二者互逆。对每个特征场 `q_p = ml(p,:)·U`，用仓库的
`interpolate_dispatch` 插值到半节点，再 `U_{j+1/2} = mr·q_half`。

若重构的 `ρ` 或 `p` 低于模板最小值的 0.1%，该半节点改用中心状态。

## 4. Steger-Warming 分裂

```
eps2 = 0.12²,  sig = 0.5/γ
λ1 = u,  λ4 = u + c,  λ5 = u - c
λk± = (λk ± sqrt(λk² + eps2))/2
diss = -sig (2λ1 - λ4 - λ5)
disp = sig (λ4 - λ5) c
fp(1) = diss + λ1
fp(2) = u diss + u λ1 + disp
fp(3) = (α + c²/β) diss + (α + p/(ρβ)) λ1 + u disp
E_{j+1/2} = ρ_L fp + ρ_R fn
```

`fp` 用左状态的 `+` 特征值，`fn` 用右状态的 `-` 特征值。

## 5. 差分算子

节点右端项 `K_j = -dE/dx`：

```
WCNSE2:  (E_{j+1/2} - E_{j-1/2}) / h
WCNSE4:  [(9/8)(E_{j+1/2} - E_{j-1/2}) - (1/24)(E_{j+3/2} - E_{j-3/2})] / h
WCNSE6:  [(75/64)(E_{j+1/2} - E_{j-1/2}) - (25/384)(E_{j+3/2} - E_{j-3/2})
          + (3/640)(E_{j+5/2} - E_{j-5/2})] / h
HCS4:    [(4/3)(E_{j+1/2} - E_{j-1/2}) - (1/6)(E_{j+1} - E_{j-1})] / h
HCS6:    [(64/45)(E_{j+1/2} - E_{j-1/2}) - (2/9)(E_{j+1} - E_{j-1})
          + (1/180)(E_{j+2} - E_{j-2})] / h
```

公式前的整体负号已包含在 `K_j` 中。`AUTO` 按插值阶数配对：
三阶 → `HCS4`，五阶 → `HCS6`。

## 6. 时间推进、边界与保护

四步四阶 Runge–Kutta（RK4）。时间步

```
dt = CFL h / max_j (|u_j| + sqrt(p_j/ρ_j))
```

默认 `CFL = 0.1`，最后一步截断到 `Tend`。边界为 7 层零阶外推。
每个 RK 阶段后，若 `ρ < 1e-8` 或 `p < 1e-8`，该单元用旧状态
`(U_{j-1} + U_{j+1})/2` 替换。日志记录保护触发次数。

## 7. 精确解

精确解只用于 Sod/Lax。先由牛顿迭代求中心区压力 `p*`：

```
f(p*, p_L, ρ_L) + f(p*, p_R, ρ_R) = u_L - u_R
```

其中激波侧用 `f = (p-p_K)/(ρ_K c_K sqrt(...))`，膨胀侧用
`f = 2c_K/(γ-1) ((p/p_K)^((γ-1)/(2γ)) - 1)`。迭代使用精度相关容差，
不收敛时退回二分法。随后得到 `u*`、`ρ*_L`、`ρ*_R` 与各波速。

采样坐标必须用 `ξ = (x - 0.5)/t`，因为初始间断在 `x = 0.5`。
按 `p*` 与 `p_L`、`p_R` 的关系区分双激波、双膨胀（含真空）、
左激波/右膨胀、左膨胀/右激波四种波型。`t = 0` 时直接返回左右初值。
